How to Use This App LoopLog

About the Home Screen

You can create a new group or task using the “+” button at the bottom right of the Home screen.
Created groups are displayed on the Home screen, and tasks within each group are shown in order of the nearest upcoming execution date.

Group Actions

  • Reorder groups: Long-press and drag anywhere inside a group card to move it up or down
  • Collapse / expand: Tap the chevron icon on the right side of the group title bar
  • Open the group task list: Tap the group title bar

Group Task List Screen

  • Edit group: Tap the edit icon in the top-right corner to change the group name, group color, and the number of tasks shown (The “number of tasks shown” refers to how many tasks are displayed inside the group card on the Home screen.)
  • Delete group: Tap the delete icon in the top-right corner to remove the group (Note: All tasks belonging to the group will also be deleted.)

Executing Tasks

Tap a task on the Home screen or on a group task list to open the Task Details screen.
From the “Add New Execution Record” button on the Task Details screen, you can record the execution date and time, a memo, and one image (memos and images are optional).

  • After execution, the next execution date is automatically updated based on the configured repeat interval.
  • For irregular tasks, you can turn off the repeat setting.
  • Past records can be viewed, edited, or deleted from “Task Details” → “Execution History.”
  • “Skip this execution” skips the current execution without creating a record.

About Notifications

You can enable notifications and set the notification timing from the task creation or task edit screen.

Note: Notifications may be delivered later than the scheduled time. This is due to system limitations related to Google’s permission policies (such as “Exact Alarms”) and is not a malfunction of the app.
